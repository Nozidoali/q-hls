# Q-HLS logos

These are the approved outline weather marks. All icons use a 200 × 200 SVG
viewBox, the same hexagonal boundary, and a transparent background. The artwork
contains vector paths only and does not depend on installed fonts.

Use the original colors and preserve the aspect ratio. The shared
`toolkit.svg` arranges the seven marks in a row for the toolkit README.

Each project's matching copy is stored at `docs/assets/logo.svg`. When artwork
changes, update both the project copy and the copy in this directory.
